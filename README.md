## AI တွေ ပြောင်းသုံးတော့ coding ရေးသည့် အချိန် မရှိတော့ အဆင်ပြေလား

အရင်ကလည်း coding မရေးပဲ junior တွေကို ပြောရ mid level တွေကို guide ပေးရ။ PR review လုပ်ရနဲ့ ပဲ​အချိန်ကုန်နေတာပဲ။ Senior သမားတစ်ယောက် အနေနဲ့ အရင်က လူ ကို ခိုင်းသည့် အစား AI ပြောင်းသွားတာပဲ ရှိ။ အလုပ်ပိုင်းမှာ သိပ်ပြီး ကွာခြားမှု မရှိ။

## မသိသည့် language , framework တွေကို AI ခိုင်းလိုက်လို့ အဆင်ပြေလား

document ကို အရင်ဖတ်။ ဘာတွေ လုပ်လို့ရလည်း နားလည်ဖို့ အရင်လုပ်ဖို့ လိုတယ်။ AI ပြောတိုင်း မှန်နေတာ မဟုတ်ဘူး။ မရေးတတ်ရင်တောင် နားလည်အောင် document တွေ အရင်ဖတ်ပြီး မှ AI ကို ခိုင်း။

ဥပမာ Rag ရေးတုန်းက Agent တွေ ခွဲမဆောက်ပဲ AI က ရေးထားသည့် အတွက် document မဖတ်ထားရင်​ရပြီ ထင်နေမှာ။ document ထဲမှာ AI gent တွေ tool calling တွေ standard တွေ ပါလို့ သူ့ကိုပြောပြီး ပြန်ဆောက်ခိုင်းရ။ document မဖတ်ထားရင်တော့ AI ပြောသည့် အတိုင်းလုပ်နေရမှာပဲ။  Document ဖတ်ထားရင်တော့ AI ကို ဘာခိုင်းရမလဲ ဘယ်လို ခိုင်းရမလဲ သိလိမ့်မယ်။

## တပြိုင်တည်း Agents ဘယ်နှစ်ခု နဲ့ လုပ်နေလဲ

ပုံမှန် ၂ ခု။ PR ပါလာရင် ၃ ခု ။ worktree ၃ ခု ခွဲပြီး Agents ၃ ခု နဲ့ တပြိုင်တည်း အလုပ်လုပ်တယ်။ တစ်ခု ဆောက်နေချိန်မှာ နောက်တစ်ခု လုပ်နေတယ်။

## Company တွေ ပြောင်းဖို့ လုပ်နေတယ်။ ဘယ် workflow ကို အကြံပေးလဲ

လက်ရှိ ဒီ event မှာ ပြောထားတာကတော့ ကျွန်တော် သုံးနေသည့် workflow ပဲ။ System တစ်ခု ကို အရင် တည်ဆောက်။ System ကို တည်ငြိမ်အောင်လုပ်။ ပြီးသွားရင် developer အဟောင်းပဲ ဖြစ်ဖြစ် အသစ်ပဲ ဝင်လာလာ System ထဲမှာပဲ အလုပ်လုပ်ခိုင်းဖို့ လိုတယ်။ ဒါဆိုရင် Coding standard , code review standard, PRD template တွေ အကုန်လုံးက standard ကိုယ်စီ ဖြစ်သွားမယ်။ Company အနေနဲ့ Developer ကို မှီခို နေစရာမလိုဘူး။ Workflow နဲ့ စနစ် တစ်ခုကို တည်ဆောက်ဖို့ လိုတယ်။ လူအားကိုးခြင်းထက် system ပေါ်မှာ တည်ဆောက်ဖို့ လိုတယ်။

## Domain Knowledge ဘယ်လို လေ့လာရမလဲ

Domain Knowledge က လေ့လာရတာ မဟုတ်ပဲ​ research လုပ်ရတာပါ။ project မစခင်မှာ project နဲ့ ဆိုင်တာ ကို နားလည်ရမယ်။ ဥပမာ Markdown Editor တစ်ခုလုပ်မယ် ဆိုရင် Markdown Syntax ကို သိရမယ်။​ Syntax Highlighting ဘယ်လိုလုပ်ရမယ် ဆိုတာ သိရမယ်။​ မသိရင်လည်း ဘာတွေ လိုအပ်လဲ။ မသိတာတွေ ဖြစ်မနေအောင် AI ကို သုံးပြီး research လုပ် လေ့လာရတယ်။ ကျွန်တော်တို့ အခု ရုံးမှာ ရေနံ တွင်း ကိစ္စတွေ လုပ်သည့် အခါမှာ တစ်ခါမှ မလုပ်ဖူးတာတွေ။ ဒါတွေကို ကျွန်တော် ပြန်လေ့လာရတာပဲ။ စာတွေ ပြန်ဖတ်ရတာပဲ။ Domain Knowledge ဘယ်လို လေ့လာရမလဲ ဆိုတာထက် research လုပ်ရမှာပါ။
